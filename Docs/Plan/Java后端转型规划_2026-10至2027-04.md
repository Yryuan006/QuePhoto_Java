# 2026 年 10 月：Java 基础与语言迁移

## 本月目标

从“不会 Java”达到“可以独立使用 Java 完成普通编程任务”。

本月暂时不要急着学习复杂框架，重点解决 Java 语言本身，同时开始适应 Java 生态。

## 学习内容

### Java 基础

- Java 项目基本结构
- 变量、数据类型、运算符
- 条件判断与循环
- 方法
- 类与对象
- 封装、继承、多态
- 抽象类与接口
- `String`
- 数组
- `ArrayList`
- `HashSet`
- `HashMap`
- 泛型
- 异常处理
- Lambda
- Stream 基础
- IO 基础

### Java 工具链

- IntelliJ IDEA
- Maven 基础
- Git 基础
- JUnit 基础

### 数据结构与算法

每周约 3 道简单题，重点是熟悉 Java 写法，不追求数量。

优先：

- 数组
- 字符串
- 哈希表
- 链表
- 栈
- 队列

## 摄影项目

暂时不重构整个小程序。

先使用 Java 对摄影业务进行建模：

- `Photo`
- `Album`
- `User`
- `Tag`

练习：

- 使用 `List<Photo>` 保存照片。
- 使用 `Map` 建立照片索引。
- 照片增删改查。
- 按时间、热度等字段排序。
- 模拟分页。

## 月底验收标准

做到以下事情时不需要频繁查 Java 基础语法：

- 自己设计并创建类。
- 熟练使用 List / Map。
- 写普通业务逻辑。
- 使用异常处理。
- 使用 Maven 管理项目。
- 使用 Git 提交代码。

**关键成果：Java 语法不再成为学习后端的主要障碍。**

正式开始 Java 后端重构。

```text

    ↓

    ↓
```

- `user`
- `photo`
- `album`
- `tag`

```text

POST   /photos

POST   /albums
```

# 每周时间建议

在正常工作的情况下，每周控制在约 **10–15 小时**。

每天 1–1.5 小时：

- Java / Spring / 数据库学习
- 少量练习代码

休息，或者完成 1 道算法题 / 简单复习。

### 周六

3–4 小时：

- 摄影项目开发
- 集中解决一个完整功能

### 周日

2–4 小时：

- 项目
- 算法
- 本周复盘
- 下周计划
